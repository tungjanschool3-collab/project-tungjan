# คู่มือติดตั้ง โปรแกรมคุมเงินนอกงบประมาณ

เว็บนี้เป็นแบบ **"ไฟล์เดียวเปิดใช้ได้เลย"** ไม่ต้องติดตั้ง Node.js
ใช้ **Supabase** เก็บข้อมูลบนคลาวด์ (เปิดใช้ได้หลายเครื่อง) และนำขึ้น **Vercel** เพื่อให้มีลิงก์ใช้งาน

รหัสผ่านเข้าโปรแกรม: **044357246** (เปลี่ยนได้ในไฟล์ `config.js`)

---

## ขั้นที่ 1 — สร้างฐานข้อมูล Supabase (ฟรี)

1. เข้า https://supabase.com → กด **Start your project** → สมัคร/เข้าสู่ระบบ (ใช้ GitHub หรืออีเมล)
2. กด **New project**
   - **Name:** ตั้งชื่อ เช่น `school-money`
   - **Database Password:** ตั้งรหัสผ่านฐานข้อมูล (จดเก็บไว้)
   - **Region:** เลือก `Southeast Asia (Singapore)`
   - กด **Create new project** แล้วรอสักครู่ให้สร้างเสร็จ

## ขั้นที่ 2 — เอาโครงสร้างตารางเข้าฐานข้อมูล

1. เมนูซ้าย เลือก **SQL Editor** → กด **New query**
2. เปิดไฟล์ `supabase/schema.sql` (ในโฟลเดอร์นี้) คัดลอก **ทั้งไฟล์** ไปวาง
3. กด **Run** (มุมขวาล่าง) — ถ้าขึ้น *Success* แปลว่าเรียบร้อย
   > ตารางและข้อมูลบัญชีเริ่มต้น (อนุบาลอุดหนุน, กองทุน, อาหารกลางวัน ฯลฯ) จะถูกสร้างให้อัตโนมัติ

## ขั้นที่ 3 — เชื่อมเว็บกับฐานข้อมูล

1. ใน Supabase เมนูซ้าย เลือก **Project Settings** (รูปเฟือง) → **API**
2. คัดลอกค่า 2 อย่าง:
   - **Project URL** (เช่น `https://abcdefgh.supabase.co`)
   - **anon public** key (ข้อความยาว ๆ ใต้หัวข้อ *Project API keys*)
3. เปิดไฟล์ **`config.js`** ด้วย Notepad แล้วเติมค่า:
   ```js
   window.APP_CONFIG = {
     SUPABASE_URL: "https://abcdefgh.supabase.co",   // ← วาง Project URL
     SUPABASE_ANON_KEY: "eyJhbGci....",              // ← วาง anon public key
     ACCESS_CODE: "044357246",                        // ← เปลี่ยนรหัสผ่านได้ตามต้องการ
   };
   ```
4. บันทึกไฟล์

## ขั้นที่ 4 — ทดลองใช้ในเครื่อง

- ดับเบิลคลิกไฟล์ **`index.html`** เพื่อเปิดในเบราว์เซอร์ (Chrome/Edge)
- ใส่รหัส **044357246** → เข้าใช้งานได้เลย
- เริ่มที่เมนู **⚙️ ข้อมูลหลัก** เพื่อกรอกชื่อโรงเรียน, ครู, ยอดยกมาของแต่ละบัญชี
- จากนั้นไปที่ **✍️ บันทึกรับ–จ่าย (หน้า 1)** เพื่อกรอกรายการประจำวัน
- ระบบจะนำข้อมูลไปลงทะเบียนคุมทั้ง 3 แบบให้อัตโนมัติ

## ขั้นที่ 5 — นำขึ้น Vercel (ให้มีลิงก์ใช้งานจริง)

### วิธี A — ลากวางง่ายที่สุด (แนะนำ)
1. เข้า https://vercel.com → สมัคร/เข้าสู่ระบบ
2. ที่หน้า Dashboard กดปุ่มเมนู → **Add New… → Project**
3. เลือกแท็บ **Deploy** แบบ *drag & drop* (หรือใช้ https://vercel.com/new แล้วเลือกอัปโหลดโฟลเดอร์)
4. ลากทั้งโฟลเดอร์นี้ (ที่มี `index.html`, `config.js`, `css`, `js`) ไปวาง → กด **Deploy**
5. เสร็จแล้วจะได้ลิงก์ เช่น `https://school-money.vercel.app` เปิดใช้งานได้ทุกเครื่อง

> ⚠️ อย่าลืม: ต้องเติมค่าใน `config.js` ให้เรียบร้อย **ก่อน** อัปโหลด

### วิธี B — ผ่าน GitHub (อัปเดตอัตโนมัติเมื่อแก้โค้ด)
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repository
2. ใน Vercel กด **Add New → Project → Import** จาก repo นั้น
3. **Framework Preset:** เลือก **Other** (เพราะเป็นเว็บ static)
4. กด **Deploy**

## การนำออกข้อมูล (Excel) และการพิมพ์
- ทุกหน้าทะเบียนมีปุ่ม **⬇️ Excel เดือนนี้** / **⬇️ Excel ทั้งปี** (แยกชีตรายเดือน)
- ปุ่ม **🖨️ พิมพ์ A4** จะเปิดหน้าต่างพิมพ์ของเบราว์เซอร์
  - ตั้งค่าขนาดกระดาษ **A4**, แนวนอน (Landscape), Margin *Default*
  - เลือก **More settings → Options → Background graphics** เพื่อให้เส้นตารางเข้ม
  - ต้องการไฟล์ PDF: เลือกเครื่องพิมพ์เป็น **Save as PDF**
- ฟอนต์เอกสารใช้ตระกูล Sarabun (เทียบเท่า TH SarabunPSK). หากต้องการ TH SarabunPSK แบบเป๊ะในไฟล์ Excel
  ให้เปิดใน Excel แล้วเลือกทั้งหมด → เปลี่ยนฟอนต์เป็น **TH SarabunPSK** ขนาด 16 ได้ทันที

## หมายเหตุด้านความปลอดภัย (สำคัญ)
- โปรแกรมนี้ป้องกันการเข้าถึงด้วย **รหัสผ่านหน้าเว็บ** (044357246) ซึ่งเหมาะกับการใช้งานภายในโรงเรียน
- `anon key` ที่ใส่ใน `config.js` จะถูกฝังในหน้าเว็บ = เปิดเผยได้ ผู้ที่รู้ทั้ง URL และ key อาจเข้าถึงข้อมูลได้
  หากต้องการความปลอดภัยสูงขึ้น สามารถเปิดใช้ **Supabase Authentication** ภายหลัง แล้วปรับ Policy ให้ตรวจสอบผู้ใช้จริง
- ควรสำรองข้อมูลเป็นระยะ: Supabase → **Database → Backups** (หรือ Export ผ่าน SQL)

## โครงสร้างไฟล์
```
โปรแกรมคุมเงินนอกงบประมาณ/
├─ index.html            หน้าเว็บหลัก
├─ config.js             ⭐ ใส่ค่า Supabase + รหัสผ่านที่นี่
├─ vercel.json           ตั้งค่าสำหรับ Vercel
├─ css/styles.css        ธีม + สไตล์การพิมพ์ A4
├─ js/
│  ├─ util.js            วันที่ไทย/ตัวเลข
│  ├─ store.js           เชื่อมต่อ Supabase
│  ├─ export.js          นำออก Excel
│  ├─ app.js             เมนู/หน้า/โมดัล
│  └─ pages/             แต่ละหน้าจอ (settings, daily, ทะเบียนคุม 3 แบบ)
└─ supabase/schema.sql   ⭐ รันใน Supabase หนึ่งครั้ง
```

มีปัญหาการติดตั้ง แจ้งได้เลยครับ 🙌
